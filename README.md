# 骨格座標修正GUI

`PPP.csv`形式の骨格推定結果を元動画・連番画像の上に重ね、1フレームずつ修正するWindows向けデスクトップアプリです。

## 起動

Python 3.10以上で、最初に以下を実行してください。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

インストール後は `start.bat` のダブルクリックでも起動します。`.venv` がある場合はそのPythonを優先します。この作業環境では設定済みです。

## 使い方

1. 起動時、同じフォルダーの `PPP.csv` を自動で読み込みます。別のCSVは「CSVを開く」から選択します。
2. 「動画を開く」または「画像フォルダー」から**CSV作成時と同じ解像度・画角**の元画像を開きます。動画は音声なしで表示します。
3. 画像の先頭がCSVの何番のframeか、「画像先頭に対応するCSV frame」で指定し「適用」を押します。PPP.csvと同じ全体動画なら `0` です。
4. 左右キーまたは下部のスライダーでフレームを移動します。
5. 関節の丸をドラッグして移動します。「2回クリック」では、関節をクリックした後、移動先をクリックします。右側の関節一覧から選択して画像をクリックする方法も使えます。重なった関節や欠損した関節は一覧から選択してください。
6. 「骨格出力用動画を選択」から、骨格を重ねる元動画を選びます。編集用に動画を開いた場合は、その動画が自動で選択されます。画像フォルダーで編集した場合も、別途動画を指定できます。
7. 「動画先頭のCSV frame」に出力用動画の最初のフレームに対応するCSV番号を入力します。動画全体がframe 0から始まる場合は `0` です。編集画面用の画像の開始番号とは別に設定できます。
8. 「CSV・動画を書き出す」から、CSVと骨格付きMP4の保存先を順に選びます。CSVの初期ファイル名は `PPP_corrected.csv` です。出力用動画を「解除」するとCSVだけを保存します。

連番画像はファイル名の数字を考慮した順序（例: `frame_2.png` → `frame_10.png`）で読み込みます。**画像は連続したフレームとして扱います**。画像の抜けや別用途の画像がないフォルダーを指定してください。画像の番号自体では対応付けません。

## 操作

| 操作 | キー / マウス |
| --- | --- |
| 1フレーム戻る / 進む | ← / → |
| 再生 / 一時停止 | Space |
| 関節を移動 | 左ドラッグ / 2回クリック |
| 拡大 / 縮小 | マウスホイール（カーソル位置を中心） |
| 拡大中の表示移動 | 右ドラッグ |
| 全体表示に戻す | Home |
| 選択解除 | Esc |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Y |
| 修正後CSVを出力 | Ctrl+S |

数値入力欄での左右キー・Space等は入力操作を優先します。
右側の「表示と編集」パネルは、マウスホイールまたは右端のスクロールバーで全体を上下に移動できます。ウィンドウが低い場合も「表示を全体に戻す」「元に戻す」「やり直す」までアクセスできます。関節一覧の上では一覧を優先してスクロールし、一覧の端に達するとパネル全体をスクロールします。画像上のホイールは拡大・縮小です。

## 表示とデータの扱い

- 現フレームは人物ごとの色、前フレームは半透明の青、次フレームは半透明の赤です。前後それぞれに表示するフレーム数を1〜10で指定できます（例: 前3・後2なら現在から−3、−2、−1、＋1、＋2フレームを表示）。
- 不透明度スライダーはそのまま使えます。1フレーム先を設定値の濃さとし、2フレーム先は1/2、3フレーム先は1/3と、遠いほど薄く表示します。遠い骨格から先に描き、近い骨格と現在の骨格を上に重ねます。前後の表示は個別にオフにできます。表示対象のフレームがCSVにない場合、その骨格は表示しません。
- ゴーストの人物は `person_N_id` で対応付けます。IDがフレーム間で切り替わった人物は重ねません。
- 人物フィルターで対象の列スロットを限定できます。各フレームのIDは関節一覧に表示します。
- マウス位置は表示倍率から元画像のピクセル座標に戻して保存します。画像の外への配置は行いません。
- CSVは1行1フレーム。`frame` と `person_N_関節名_x` / `_y` が必須です。`time_seconds`・`_id`・`_score`や追加列を保持します。関節線はPPP.csvの日本語17関節名に対応します。
- 出力では列順・行順・空欄・未修正セルの文字列表現を保持し、修正したx/yのみ変更します。UTF-8 BOM付きCSVで保存します。CSVの引用符や改行の表現は標準CSVライターで再構成します。
- 信頼度scoreはAI推定時の値として保持します。手動修正しても1.0などに変更しません。空欄の関節を配置した場合もIDやscoreは自動補完しません。
- Undo / Redoはフレームをまたいで動作します。未保存のまま終了・CSV切り替えを行う際は確認します。
- 画像上の修正前に、フレーム対応・解像度・画角をご確認ください。リサイズ・切り抜き済み画像と元解像度の座標は自動変換しません。

## 骨格付き動画

- 動画は元動画の全フレーム・解像度・fpsでMP4として保存します。CSVに対応行がないフレームは骨格なしで出力します。音声は含みません。
- 参照元の `rtmlib` 0.0.16 / COCO17と同じ関節・骨格線、色、点の半径2px、線の太さ2pxで描画します。編集画面の前後フレームの半透明表示や人物フィルターは動画には反映せず、全人物の当該フレームの骨格を描きます。
- 元コードと同じく、未修正の関節は推定scoreが0.45以上の場合に表示します。手動で位置を修正した関節は、scoreが低くても表示し、接続先が表示される場合は骨格線も描きます。CSVのscoreは変更しません。保存済みCSVを開き直した場合、以前の手動修正は識別できず、そのCSVに記録されたscoreで判定します。
- 出力用動画と編集画面の画像は、同じ解像度・画角・フレーム番号に合わせてください。CSVの全フレームが出力用動画に収まらない場合や、編集画像と動画の解像度が異なる場合は書き出しを中止します。MP4作成には幅・高さが偶数の動画が必要です。
- 動画の読み込みにはPyAVを使用します。読み込み時に映像を一度最後までデコードし、実際のフレーム数と表示順を確認するため、長い動画では最初に時間がかかります。動画情報上のフレーム数が実際と異なっていても、実際に読み取れたフレーム数でCSVと対応付けます。骨格描画とMP4書き出しには従来どおりOpenCVを使用します。

## 付属データ

`PPP.csv` は281行（frame 0〜280）、158列、17関節×3スロットです。実座標はperson_0 / ID 1にあり、時刻間隔は約23.976fpsです。元動画・画像は付属していません。

## 検証

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

実動画の回帰テストは、環境変数 `POSE_TEST_VIDEO` に対象の `C0034.MP4` のパスを設定して実行できます。動画情報284フレーム・実デコード281フレームのファイルで、末尾への移動、逆方向移動、CSV frame 0〜280の動画出力を確認します。生成物はテスト後に削除します。
